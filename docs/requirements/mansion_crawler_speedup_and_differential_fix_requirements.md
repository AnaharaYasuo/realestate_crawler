# マンション系クローラー中間ページ並行化・WAF適正緩和および野村差分抽出修復 要件定義書 (Issue #867)

## 1. 概要 / ユーザーストーリー
* **ユーザーとして**: 不動産クローラー運用管理者として
* **目的**: 三井・野村・住友・東急などのマンション系クローラーの実行時間を大幅に短縮し、差分スキップを正常に機能させる。
* **価値**: 物件数が最も多い大手マンション系サイトにおいて、中間ページ（Start / Region / Area）が1並列で直列実行されており、探索に膨大な待機時間が発生している。また野村では一覧カードからの価格抽出漏れ（Price=None）により差分スキップが機能せず全件詳細取得が走り、過度な負荷と時間浪費が生じている。これを解消し、探索を高速化して差分スキップを完全機能させる。

## 2. 機能要件 (FR)

### FR-867-001: 大手マンション系中間ページの並行度適正化
- 三井 (`mitsui.py`)、野村 (`nomura.py`)、住友 (`sumifu.py`)、東急 (`tokyu.py`) の中間ページクラス（Start / Region / Area）において、`_getLocalPararellLimit()` および `_getCloudPararellLimit()` の並行数を 1 から **3** に引き上げること。
- 一覧ページ（List ➔ Detail）へのディスパッチは各社の詳細並列キャップ（WAF防御）が自動適用され、相手先サーバーへの突発過負荷を物理的に防止すること。

### FR-867-002: WAFレートリミットおよび並行キャップの適正緩和
- `ParseDetailPageAsyncBase.SITE_DOWNLOAD_DELAYS` において、`mitsui` および `nomura` のリクエスト間隔ディレイを 1.0s から **0.5s** に緩和すること。
- `AdaptiveConcurrencyController.SITE_CONCURRENCY_CAPS` において、`mitsui` および `nomura` の並列キャップを 2 から **3** に適正緩和すること。

### FR-867-003: 野村不動産（nomu.com）一覧カード価格抽出の修復
- `baseParser.py` の `_find_card_container` において、`div.item_title` 等のタイトル用ラッパー要素で探索を誤認停止せず、価格を含む上位カードコンテナ（`div.item_resultsmall` 等）まで正しく遡って探索すること。
- 野村の一覧ページにおいて `ListItem.price` が正常抽出され、`filter_differential_items` による差分スキップが機能すること。

## 3. 非機能要件 (NFR)
- **NFR-867-001 (探索速度向上)**: 中間ページ（Area / Region）の巡回時間が従来の約1/3に短縮されること。
- **NFR-867-002 (WAF403防御維持)**: レートリミット緩和後も 0.5s のディレイと最大3並列のガードにより、相手サーバーからの403 WAF遮断を確実に防止すること。
- **NFR-867-003 (単体・回帰テスト全件合格)**: 既存のテストおよびパーサー抽象メソッド検証、ミューテーションテストが全て合格すること。
