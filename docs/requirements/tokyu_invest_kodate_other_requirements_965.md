# 東急リバブル投資用戸建て conditions-use=other からの判別抽出 要件定義 (Issue #965)

## 1. 概要
東急リバブル投資用物件（`/fudosan-toushi/`）には戸建て専用の用途URLパラメータ（`conditions-use=kodate` 等）が存在せず、従来は戸建て投資物件の抽出が行えなかった。
調査の結果、その他建物カテゴリ（`conditions-use=other/`）内に投資用一戸建て物件が「その他(土地・建物)」として混在していることが判明した。
本要件では、東急リバブル投資用戸建てクローラーの開始URLを `conditions-use=other/` に変更し、ホテル・旅館・ビル・マンション・店舗等の非戸建て物件を除外して戸建て物件のみを確実に判別抽出する要件を定める。

## 2. 背景と課題
1. **従来URLの仕様**:
   - `conditions-use=kodate` は存在せず、全件（3,600件超）または空結果となっていた。
2. **`conditions-use=other/` の混在実態**:
   - 200件超の物件が存在し、ホテル、旅館、立体駐車場、ビル一棟、マンション一棟売、店舗・事務所などが混在。
   - 一方で、「その他(土地・建物)」かつ戸数1戸（または'-'）、木造/軽量鉄骨2〜3階建の戸建て投資物件（40〜150m²程度）が数十件含まれている。
3. **誤抽出および漏れの防止**:
   - 複数戸の木造アパート（例: 6戸、14戸）や中高層RCビル（4階以上）の混入を遮断し、戸建て物件のみを正しく抽出・保存する。

## 3. 受入基準 (Acceptance Criteria)
- **AC-965-1 (クローラー開始URLの変更)**:
  - `ParseTokyuInvestKodateStartAsync.urlList` を `["https://www.livable.co.jp/fudosan-toushi/tatemono-bukken-all/conditions-use=other/"]` に設定すること。
- **AC-965-2 (一覧ページにおける一次フィルタリング)**:
  - Next.js JSON (`propertyList`) の各物件に対し：
    - `labelList` に除外対象ラベル（`ホテル`, `旅館`, `車庫・立体駐車場`, `車庫`, `立体駐車場`, `店舗`, `事務所`, `倉庫`, `工場`, `寮・社宅`, `医療施設`, `マンション一棟売`, `アパート一棟売`, `ビル一棟`, `リゾートマンション・別荘`）が含まれている場合はスキップすること（スラッシュ区切りの複合ラベルも個別判定）。
    - ラベルに `その他(土地・建物)` が含まれていることを確認すること。
    - `propertyDetail` の戸数表記が2戸以上の複数戸物件（例: `2戸`, `6戸`, `14戸` 等）はスキップすること（`'-'`, `1戸`, または戸数未記載のみ許可）。
    - `propertyDetail` の階数表記が地上4階以上の高層物件（例: `地上4階建`, `地上5階建` 等）はスキップすること。
- **AC-965-3 (詳細ページにおける二次ガード)**:
  - 詳細パース時、物件名・タイトル・見出しに「マンション」「区分」「ビル」「店舗」「アパート」「ホテル」等が含まれる場合はスキップすること。
  - 土地面積（`tochiMenseki`）が取得できない場合はスキップすること。
- **AC-965-4 (テストとE2E検証)**:
  - 単体テストで除外ケースと抽出対象ケースの判定精度を検証すること。
  - 実際に東急リバブル投資用戸建てクローラーを実機検証し、1件以上の戸建てが抽出されること。
