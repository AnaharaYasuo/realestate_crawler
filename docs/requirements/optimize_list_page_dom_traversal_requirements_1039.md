# 要件定義書: 一覧ページ価格抽出のDOM走査最適化 (Issue #1039)

## 1. 背景と目的
一覧ページのパース処理（`_parsePageCore`）において、ページ内に存在する大量の `<a>` タグごとに、親コンテナ探索（`find_parent` 最大6階層）および 9 種の CSS セレクタによる子孫再帰走査（`select_one`）を実行していたため、1 ページあたり数万〜数十万回の DOM 全走査が発生し、CPU / GIL が長時間の膠着状態に陥っていた。
本改修では、カード単位または要素単位での走査結果のメモ化（キャッシュ）および無駄な再帰探索の早期打ち切りを導入し、抽出精度を 100% 維持したままパース所要時間を大幅（ミリ秒オーダー）に短縮する。

## 2. 要件一覧
1. `_extract_card_price` において、同一親コンテナに対する価格探索結果をキャッシュ（メモ化）し、同一カード内の複数リンクで重複する DOM 全走査を排除する。
2. 既に価格を持たないと判定された親階層や、価格特定済みの親階層の再探索をスキップする。
3. 既存のすべてのテスト（価格抽出の回帰テスト・ユニットテスト・統合テスト）が全件合格すること。
