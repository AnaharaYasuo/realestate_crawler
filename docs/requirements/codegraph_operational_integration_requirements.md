# CodeGraph 運用組み込み 要件定義書

## 1. 背景と目的
不動産クローラーリポジトリの大規模化に伴い、コードベース全体のシンボル・クラス・関数・呼出経路および影響範囲（Blast Radius）を正確かつ迅速に把握することが極めて重要となっている。
従来の手動 `grep` やファイル全体の `view_file` では、不要なトークン消費、探索漏れ、依存関係の見落としが生じるリスクがあった。
本改修では、導入済みの CodeGraph CLI および MCP（`codegraph_explore`）を開発ライフサイクルおよび日常運用に深く組み込み、コード解析の標準化とインデックスの自動追従を恒久的に実現する。

## 2. 対象スコープ
- **Git フック連携**: `post-merge` および `post-checkout` フックによるインデックス同期（`codegraph sync`）
- **タスクランナー連携**: `Taskfile.yml` への `task codegraph:sync` タスク追加
- **開発行動規範（`.agents/AGENTS.md`）の改定**:
  - CodeGraph ファースト調査原則の義務化
  - Pre-Flight Sync（最新 master 同期）時のインデックス更新フロー追加
  - Worktree 環境における CodeGraph 適用規則の明文化
- **自動テスト・検証機構**: フックおよび同期コマンドの実行性検証テスト

## 3. 機能要件 (FR)
- **FR-001 (自動インデックス同期)**: `git pull` (merge) またはブランチ切り替え (checkout) 発生時、自動的またはバックグラウンドで `codegraph sync` を呼び出し、インデックス差分を反映すること。
- **FR-002 (フック耐障害性・非ブロッキング)**: CodeGraph CLI が未インストールまたはエラーとなった場合でも、Git 本来の merge/checkout 処理を阻害しないフェイルセーフ仕様（exit 0 保証）とすること。
- **FR-003 (タスクランナー提供)**: `task codegraph:sync` コマンドにより、開発者や CI/スクリプトから容易にインデックス同期を実行可能とすること。
- **FR-004 (AIエージェント探索強制)**: AI エージェント（Antigravity / Cursor 等）に対し、コード調査・修正・影響範囲分析における `codegraph_explore` のファーストコールを運用ルールで強制すること。

## 4. 非機能要件 (NFR)
- **NFR-001 (パフォーマンス)**: インデックス同期は増分同期 (`codegraph sync`) とし、開発者の作業ブロック時間を最小化すること（通常 10秒以内）。
- **NFR-002 (クロスプラットフォーム親和性)**: Windows (PowerShell / cmd.exe / Git Bash) および Linux/WSL 環境のいずれでも安全に動作すること。
- **NFR-003 (ゼロデッドロック)**: SQLite の WAL モードと整合し、MCP サーバー起動中であっても同期が安全に完了すること。
