# 要件定義: 都市部・地方の感応度差を調整する交互作用特徴量の導入 (Issue #1003)

## 1. 概要 / 背景
現行の不動産価格推論システム（`package.ml`）は全国共通の単一アンサンブルモデル（LightGBM, XGBoost, CatBoost, RandomForest）を採用している。
しかし、「駅徒歩（`walk_min`）」「築年数（`chikunen`）」「面積（`area`）」などの特徴量は都市部と地方で価格形成への感応度（弾力性）が大きく異なる。
感応度の変調因子となる環境特徴量をモデルに与えないまま同一尺度を機械的に適用した結果、
- 東京都心・大都市圏高額帯での過小評価（サチュレーション）
- 地方中核・郊外物件での過大評価およびお宝物件（割安通知）の誤検知
が発生している。
本要件では、配信フィルターはいじらず、価格予測特徴量に都市度・立地密度・土地建物比率に基づく「感応度変調特徴量（交互作用項）」を導入し、単一モデルのまま都市部と地方の適正評価を実現することを目的とする。

## 2. 要件一覧
1. **駅徒歩感応度変調要件**:
   - 人口密度および駅乗降客数と連動し、都市部ほど徒歩ペナルティが急峻になり、地方・車社会ほど緩やかになる交互作用項を算出すること。
2. **築年数・上物価値感応度変調要件**:
   - 土地と建物の潜在価値比率（`land_value_share`）を算出し、土地主導（都心・高額地価）では築古減価が緩やかになり、建物主導（地方・低地価）では築年減価が強く効く交互作用項を算出すること。
3. **面積感応度変調要件**:
   - 地価水準および容積率需要と連動し、都心一等地での面積増（プレミアム）と地方低密度地での面積増（規模減価）を表現する交互作用項を算出すること。
4. **互換性および安全性要件**:
   - `prepare_df_features` で未定義列・欠損値が自動的に 0.0 で初期化・ベクトル化され、既存モデルのロードおよび推論に破壊的影響を与えないこと。
