# 投資物件利回り補正およびバリデーション許容境界の是正 要件定義書 (Issue #791)

## 1. 概要
東急リバブル等の投資物件において、年間想定賃料が取得できているにもかかわらず表面利回りが未記載の場合に `grossYield=0.0` と補正され、データバリデーション（`PropertyDataValidator`）で利回り異常（0.0%）として判定され自己修復アラートが継続検知される事象を解消する。また、LIFULL HOME'S等の投資ポータルに掲載された100万円未満の低価格物件や20億円超の実在高額物件がバリデーションエラーとして誤判定される事象を是正する。

## 2. 目的とスコープ
* **目的**:
  1. 利回りが未記載だが価格と想定賃料が判明している投資物件において、表面利回りを自動計算して `grossYield` に補完する。
  2. 投資ポータル由来の低価格物件（1万円〜100万円未満）の許容判定を拡充する。
  3. 20億円超〜50億円以下の超高額物件に対する誤判定を防止する。
* **スコープ**:
  - `src/crawler/package/parser/baseParser.py`
  - `src/crawler/package/utils/data_validator.py`
  - 関連ユニットテストおよび仕様ドキュメント

## 3. 要件一覧
* **REQ-791-01**: `_guard_gross_yield` において、`grossYield` が空または0の場合に `price > 0` かつ `annualRent > 0`（または月額賃料）があれば、自動的に表面利回りを算出して `grossYield` に格納すること。
* **REQ-791-02**: `data_validator.py` の `_is_low_price_allowed` において、URLに `toushi` または `invest` を含む物件は1万円以上の低価格を許容すること。
* **REQ-791-03**: `data_validator.py` の価格上限チェック閾値を20億円から50億円に緩和すること。
