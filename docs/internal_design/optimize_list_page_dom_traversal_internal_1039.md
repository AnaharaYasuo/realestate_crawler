# 内部設計書: 一覧ページ価格抽出のDOM走査最適化 (Issue #1039)

## 1. 最適化ロジック
- `_parsePageCore` 内で `card_price_cache: dict[int, int | None] = {}` を初期化。キーは親コンテナまたは link の `id(element)`。
- `_find_card_container` で特定された `card` 要素の `id(card)` がキャッシュにあれば、CSS セレクタ走査（`select_one`）をスキップして即座に価格を返す。
- これにより、1つのカード内に写真リンク、タイトルリンク、詳細ボタンなど複数の `<a>` があっても、DOM 探索は最初の1回だけで完了する。
- さらに、CSS セレクタ走査時、親コンテナ内のテキスト自体に価格パターンが存在しない場合はセレクタ走査自体をバイパスする。
