# 掲載終了ページ共通ハンドリング要件定義書 (Issue #600)

## 1. 概要 / 背景

不動産情報サイトでは、成約や売主都合等により物件掲載が予告なく終了する。
掲載終了となった物件ページにアクセスした場合、以下のいずれかの挙動となる：
1. HTTP 404 / 410 で応答する
2. HTTP 200 で応答するが、HTML 内に「掲載終了」「成約済み」「お探しの物件は見つかりませんでした」といった終了告知メッセージを表示し、スペック表や物件名要素が存在しない

後者の場合、パーサーが通常物件としてパースを試行し、必須フィールド（物件名・価格等）の抽出失敗による例外（`ReadPropertyNameException` や `LoadPropertyPageException`）が発生していた。
これにより、エラーログの肥大化、不要なエラーHTMLの保存、リトライによるクロール遅延、および Slack アラートチャンネルへの誤検知通知（エラーアラート）が発生する問題があった。

本改修では、全パーサーの基底である `ParserBase` において、タイトルおよび HTML 本文の掲載終了フレーズを包括的に検知し、即座に `ListingEndedException`（`SkipPropertyException` の派生）を送出してクローリングエラーと判定させない仕組みを確立する。

---

## 2. ユーザーストーリー

* **ユーザーとして**、不動産クローラー運用者
* **目的**: 物件詳細ページが「掲載終了」「成約済み」「お探しの物件は見つかりませんでした」等の公開終了状態だった場合に、クローリング処理全体でエラーやリトライ失敗（500/例外）にならず、正常にスキップ（`ListingEndedException` / `SkipPropertyException`）として扱われるようにしたい。
* **なぜなら**: 掲載終了ページに対して必須項目パース失敗等の例外が発生してエラーログやエラーHTML保存、Slackエラー通知に計上されるのを防ぎ、クローラーの安定性を高めるため。

---

## 3. 機能要件

### FR-LE-001: 共通掲載終了キーワード・フレーズの網羅検知
* `ParserBase` の `_raise_on_listing_title` または新設の包括的チェックメソッド（`check_listing_ended`）において、タイトル（`<title>`）および HTML 本文（`<body>`）から以下の主要フレーズを検知すること：
  * `掲載終了`
  * `掲載が終了`
  * `掲載を終了`
  * `成約済み` / `ご成約`
  * `お探しの物件は見つかりません` / `お探しの物件は、掲載が終了` / `お探しのページは見つかりません` / `お探しのページは存在しない`
  * `指定された物件は掲載を終了` / `ご指定の物件は掲載を終了`
* 上記のいずれかが検知された場合、即座に `ListingEndedException` を送出すること。

### FR-LE-002: 基底パーサーによるパース前一括検知
* `ParserBase.parsePropertyDetailPage` において、HTML コンテンツ取得直後（`_soup_from_content` 生成直後）に共通掲載終了チェックを実行すること。
* 各社パーサー（`athomeParser.py`, `tokyuParser.py`, `mizuhoParser.py` 等）の個別パース処理に到達する前に検知・送出されること。

### FR-LE-003: エラーログ・エラーHTML保存・Slack通知の除外
* `ListingEndedException` は `SkipPropertyException` を継承しているため、`api.py` の `_fetch_detail_item` において「Expected / Listing Ended」として情報ログ（INFO）のみ記録し、エラーログ（ERROR）や `_save_error_html_by_url`、`CrawlerReporter.failure` を行わないこと。
* リトライ処理（Retry）を実行せず、直ちに当該物件をスキップすること。

---

## 4. 非機能要件

### NFR-LE-001: パフォーマンス（高速判定）
* タイトルチェックを最優先で実行し、タイトルに掲載終了が含まれる場合は本文全体のテキスト抽出を行わずに即座に判定を完了すること。
* 本文テキスト走査が必要な場合でも正規表現の事前コンパイルまたは文字列 `in` 検索を用い、DOM走査のオーバーヘッドを最小化すること。

### NFR-LE-002: 誤検知防止
* 物件概要や備考欄に「掲載終了時はご了承ください」などの免責条項が含まれる可能性を考慮し、タイトル（`<title>`）および見出し（`<h1>`, `<h2>`）、あるいは主要エラーメッセージ領域を優先的に判定すること。

---

## 5. 受入基準 (Acceptance Criteria)

1. **AC-1**: タイトルまたは見出し/本文に掲載終了キーワード（「掲載が終了したか、成約済みになった可能性があります」「掲載を終了いたしました」等）が含まれる HTML に対し、`parsePropertyDetailPage` が `ListingEndedException` を送出すること。
2. **AC-2**: `ListingEndedException` 発生時、`api.py` がエラーHTMLを保存せず、リトライも行わず、正常スキップとして処理を完了すること。
3. **AC-3**: 正常な物件詳細ページにおいて、誤検知によるスキップが発生しないこと。
4. **AC-4**: 全単体テストが通過すること。
