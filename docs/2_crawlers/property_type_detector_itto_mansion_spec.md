# PropertyTypeDetector 単独「一棟」誤判定防止仕様 (#1877)

## 1. 背景
中古マンション（区分所有）の物件名自体に「一棟」が含まれるケース（例: `大和サニーハイツ高槻一棟 6階3LDK｜高槻市の中古マンション購入`）において、`PropertyTypeDetector._match_keywords()` が `APARTMENT_KEYWORDS` 末尾の単独語 `"一棟"` に先にヒットし、`apartment` と誤判定される不具合が発生した。

## 2. 仕様
- `APARTMENT_KEYWORDS` のうち明示的な一棟・収益複合語（`一棟売りアパート`、`一棟アパート`、`一棟売りマンション`、`一棟マンション`、`一棟売りビル`、`一棟ビル`、`収益アパート`、`投資用アパート`、`収益物件`、`一棟売り`）にヒットした場合は、従来通り最優先で `"apartment"` を返す。
- 単独語 `"一棟"`（`KW_ITTO`）のみにヒットした場合、同一テキスト内に明示的な区分マンション複合語（`区分マンション`、`中古マンション`、`新築マンション`、`区分所有`）が含まれ、かつ戸建キーワード（`一戸建`、`戸建`）が含まれない場合は `"mansion"` を優先して返す。
- 明示的な区分マンション複合語が共起しない単独 `"一棟"` は、従来通り `"apartment"` を返す。
