# 共通データ正規化・クレンジング規約 (Data Normalization & Cleansing Standards)

## 1. 概要と基本原則
各パーサー内で個別実装され、品質のムラやサイレント不整合（空文字化・フォーマット破綻）を引き起こしていたデータ変換・クレンジング処理を、パーサーから完全に分離し、共通の `DataNormalizer` パイプラインとして一本化する。

- **パーサーの責務**: DOMから生のテキスト（表記揺れや不要な空白・タグを含む状態）を正確に引っこ抜くこと（`get_<field>_str`）。
- **`DataNormalizer` の責務**: サイト固有の表記ブレ、全角半角、和暦、単位を統一スキーマ型（`Decimal`, `int`, `date`, `str`）に変換すること。

---

## 2. 変換・正規化パイプライン仕様

### 2.1 数値・文字列の共通正規化
- **全角・半角統一**: 全角英数・記号（`１２３`, `，`, `．`, `㎡`）はすべて半角英数（`123`, `,`, `.`, `m2`）に変換。
- **不可視文字・空白の除去**: 改行（`\r`, `\n`）、タブ（`\t`）、連続するスペース、全角スペース（`\u3000`）を単一の半角スペースに集約またはトリム。

### 2.2 価格 (Price) 正規化
- 入力例: `"3,980万円"`, `"1億2,500万円"`, `"3980万 (税込)"`, `"3億円"`
- 変換ルール:
  - 「億」「万」の日本語単位を数値倍率（億 = `100,000,000`、万 = `10,000`）として解釈し加算。
  - 「税込」「非課税」「相談」等の付帯文字列を除去。
  - 出力: `int`（単位: 円。例: `39800000`）

### 2.3 面積 (Area) 正規化
- 入力例: `"70.52㎡"`, `"25.3坪"`, `"70.52m² (壁芯)"`
- 変換ルール:
  - 「坪」表記は `坪数 * 3.30578` により平米（㎡）に自動換算。
  - 付帯情報（「壁芯」「内法」「公簿」「実測」）を属性フラグとして分離抽出。
  - 出力: `Decimal(precision=2)`（単位: ㎡。例: `Decimal('70.52')`）

### 2.4 築年月・日付 (Built Date) 正規化
- 入力例: `"2015年3月"`, `"平成27年3月"`, `"令和3年築"`, `"昭和58年11月"`
- 変換ルール:
  - 元号マッピング（令和: `2018 + 年`, 平成: `1988 + 年`, 昭和: `1925 + 年`, 大正: `1911 + 年`）を適用して西暦に一律変換。
  - 月が未記載（「2015年築」）の場合はデフォルト `1月` として補完。
  - 出力: `datetime.date` または `YYYY-MM` 文字列。

### 2.5 住所 (Address) 正規化
- 入力例: `"東京都港区赤坂３丁目1-2"`, `"神奈川県横浜市中区山下町"`
- 変換ルール:
  - 都道府県名補完（都道府県名が省略されている場合は市区町村から逆引き補完）。
  - 数字（番地・号）の半角ハイフン統一（`３丁目１番２号` ➔ `3-1-2`）。
