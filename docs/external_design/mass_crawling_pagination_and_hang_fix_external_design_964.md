# 外部設計書: 全クローラーのページネーション・上限キャップ・ハング根絶と大量クローリング対応

## 1. システム構成・インターフェース
各サイトのパーサーおよびAPI実行レイヤーにおいて、以下の3つの共通強化を行う：

### 1.1 ページネーション（次ページURL解決）
- 各パーサーの `getPropertyListNextPageUrl` において、YAMLセレクター（`next_page` / `next_page_css`）とフォールバック（テキスト「次へ」「次のページ」・属性 `rel="next"` 等）を統一。
- 相対パスの絶対URL変換（`urllib.parse.urljoin`）および重複URL防止（`visited_urls`）を徹底。

### 1.2 検索上限（上限キャップ）の回避設計
- サイト側が「全域検索で最大100件/500件までしか表示しない」場合、エリア階層（都道府県 ➔ 市区町村 ➔ 一覧）を掘り下げて細分化URLを生成し、サイト上限を回避して全件回収する。

### 1.3 ハング根絶・有限タイムアウト保証
- NFR-021および普遍ルールに則り、すべてのHTTP非同期通信に有限タイムアウトを設定。
- 無進捗検知時のサーキットブレイカー（連続失敗時の安全終了と部分結果保持）。

## 2. サイト別修正方針
* **三井のリハウス (mitsui)**:
  - 戸建・土地のページ送りループ解消、市区町村別分割クエリの確認。
* **住友不動産ステップ (sumifu)**:
  - `limit=1000` 設定および `next_page` セレクターの最新DOM対応。
* **東急リバブル (tokyu)**:
  - マンションの100件頭打ちの解除（市区町村レベルでのエリア分割）。
* **野村の仲介+ (nomura)**:
  - マンション・土地の次ページURL抽出セレクター修正。
* **athome / homes**:
  - ヘッダー・Cookie・WAF回避設定およびセレクター整合。
* **smtrc / 電鉄系 / ハウスメーカー系**:
  - ジョブ起動パラメータ・スタートURL・次ページリンクの全面更新。
