# 外部設計書: ローカル Docker クローラー実行構成 (Issue #857)

## 1. システム構成図
```
[ローカル PC 開発環境]
  ┌────────────────────────────────────────────────────────┐
  │ Docker コンテナ (app / scheduler / crawler)             │
  │   - DB_HOST=host.docker.internal (or host)             │
  │   - DB_PORT=6033                                       │
  │   - STORAGE_BACKEND=gcs                                │
  │   - CRAWLER_PARALLEL=4 (デフォルトより抑制)              │
  │   - CRAWLER_PLAYWRIGHT_PARALLEL=1                      │
  └──────────────────────────┬─────────────────────────────┘
                             │ localhost:6033
  ┌──────────────────────────▼─────────────────────────────┐
  │ gcloud compute start-iap-tunnel                        │
  │   - IAM 認証 (roles/iap.tunnelResourceAccessor)        │
  │   - mTLS 暗号化通信 (外向き 443)                         │
  └──────────────────────────┬─────────────────────────────┘
                             │ (Google セキュア中継)
═════════════════════════════╪══════════════════════════════
[Google Cloud Platform]      │
  ┌──────────────────────────▼─────────────────────────────┐
  │ Google Cloud IAP (Identity-Aware Proxy)                │
  └──────────────────────────┬─────────────────────────────┘
                             │ (VPC 内部通信: 10.0.0.10:6033)
  ┌──────────────────────────▼─────────────────────────────┐
  │ ProxySQL GCE Instance (10.0.0.10:6033)                 │
  │   - コネクションプーリング & 多重化                      │
  └──────────────────────────┬─────────────────────────────┘
                             │ (VPC Private IP: 3306)
  ┌──────────────────────────▼─────────────────────────────┐
  │ Cloud SQL for MySQL (Private IP のみ / パブリック露出なし)│
  └────────────────────────────────────────────────────────┘
```

## 2. 外部インターフェース仕様
1. **ネットワーク & ファイアウォール**:
   - VPC ネットワークに Google IAP の CIDR (`35.235.240.0/20`) から ProxySQL インスタンス（タグ: `proxysql`）へのポート `6033` のインバウンド通信を許可するルールを追加。
2. **環境変数インターフェース**:
   - `CRAWLER_PARALLEL`: 標準クローラーの並列実行数（未指定時はデフォルト 9）。ローカル向けに 2〜4 などを設定可能。
   - `CRAWLER_PLAYWRIGHT_PARALLEL`: Playwright クローラーの並列実行数（未指定時はデフォルト 3）。ローカル向けに 1 などを設定可能。
   - `DETAIL_CONCURRENCY`: 1 ジョブ内の詳細取得並行度（未指定時は `CLOUD_DETAIL_CONCURRENCY` またはアクティブジョブ数からの自動算出）。
   - `STORAGE_BACKEND`: `gcs` を指定することで、ローカル MinIO を経由せず直接 GCS バケットへアップロード。
