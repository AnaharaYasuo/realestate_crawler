# ローカルバックグラウンドワーカー多重度制限 外部設計書 (Issue #1034)

## 1. 外部インターフェース・環境変数仕様
- `CRAWLER_LOCAL_WORKER_CONCURRENCY`:
  - 型: 整数（Integer）
  - デフォルト値: `20`
  - 説明: 同時に実行を許可するローカルバックグラウンドワーカースレッドの最大数。

## 2. 振る舞い仕様
1. **通常時（実行中スレッド数 < 上限）**:
   - リクエスト発生時、直ちにワーカースレッドが割り当てられ、処理が開始される。
2. **過密時（実行中スレッド数 >= 上限）**:
   - 上限枠が空くまで新規スレッドの起動は待機（ブロック）される。
   - 先行スレッドが1件完了すると即座に次のタスクが枠を獲得して起動する。
3. **終了待機時 (`_wait_for_active_fire_and_forget_threads`)**:
   - キューまたは待機中のすべてのタスクおよび稼働中スレッドが完了するまで待機を継続する。
