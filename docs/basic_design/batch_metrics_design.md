# バッチ処理標準メトリクス基本設計書 (Batch Metrics Basic Design)

## 1. 概要
本設計書は、要件定義書（`docs/requirements/batch_metrics_specification.md`）に基づき、学習処理（`train.py`）、価格推定処理（`run_bulk_ml_evaluation.py`）、割安物件配信処理（`send_recommendations.py`）における標準メトリクスのフォーマット仕様、Slack通知レイアウト、および共通ユーティリティの外部インターフェースを定義する。

---

## 2. 共通メトリクスフォーマット設計

## 3. 共通モジュール `BatchMetrics` インターフェース設計
共通処理を行う `src/crawler/package/utils/batch_metrics.py` を新設し、時間計算・スループット計算・メッセージ整形を統一する。

```python
class BatchMetrics:
    def __init__(self, job_name: str, total_count: int = 0):
        self.job_name = job_name
        self.start_time = time.time()
        self.end_time = None
        self.total_count = total_count
        self.processed_count = 0
        self.skipped_count = 0
        self.failed_count = 0
        self.custom_metrics = {}

    def finish(self) -> float: ...
    def elapsed_seconds(self) -> float: ...
    def throughput(self) -> float: ... # items/sec
    def latency_ms(self) -> float: ... # ms/item
    def format_duration(self) -> str: ...
    def format_log_banner(self) -> str: ...
    def format_slack_summary(self, emoji="✅") -> str: ...
```
