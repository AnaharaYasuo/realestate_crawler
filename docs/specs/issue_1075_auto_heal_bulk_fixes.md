# 外部仕様書: クローラー自己修復における系統的異常判定の包括適正化

## 1. 概要
自己修復（Auto-Healing）で検知された上位50件の異常（計1433件）について、パーサーの実際の取得機能自体は正常に稼働しているにもかかわらず、以下の3つの不整合により誤判定・誤インジェストが発生している事象を是正する。

1. **ビジネス上の注意喚起・ペナルティ情報（再建築不可・間口警告等）のパーサーバグ誤認インジェスト**:
   - 物件の適法性や接道状況を表す注意情報（「再建築不可警告」「間口0m警告」）が、Slackアラート経由で「パーサー障害」として自己修復対象に集約され、修復ループに滞留していた。
   - `auto_heal_parsers.py` において、パーサー修正対象外である「再建築不可」「間口」「ペナルティ」関連の通知行を自己修復ターゲットから除外する。

2. **投資用物件・区分物件における面積・価格バリデーションの緩和**:
   - `PropertyDataValidator`:
     - 投資用アパート・区分マンション（ptype に `apartment`, `invest` を含む、または URL/タイトルに `toushi`/`invest` を含む物件）において、専有面積が5㎡超であれば正常と判定する（ワンルーム区分やシェアハウス等に対応）。
     - 投資用物件において、利回りや賃料情報が存在する場合、あるいは低廉投資用物件（10万円〜100万円未満）における価格判定の免除基準を適正化。

3. **住友不動産（sumifu）のマンション所在階抽出の堅牢化**:
   - `SumifuMansionParser._parseKaisuRaw`: 表記ゆれ（`所在階構造` や `所在階 / 階建` 等）から確実に所在階数値を抽出する正規表現の補強。

## 2. 成果目標
- 上位50件の誤判定ターゲット（約250件の再建築不可・間口警告、約80件の投資用区分面積過小疑い）が解消し、真のパース異常のみがオートヒール対象として集約されること。
