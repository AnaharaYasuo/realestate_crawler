# 仕様書: athome土地の建ぺい率・容積率欠損およびマンション所在階パース破綻の解消 (Issue #1402)

## 1. 概要・背景
オートヒール指示書（`Temp/auto_heal_instruction.json`）において、最多発生頻度（土地107件、マンション60件）となっている athome パーサーの必須項目欠損を自己修復する。

## 2. 障害原因
1. **athome tochi (建ぺい率・容積率欠損)**:
   - 建築条件付宅地分譲等の最新ページにおいて、概要テーブルが「建蔽率/容積率」という1つのヘッダーセルにまとめられ、値が `-/- 60％・200％` のように記載されている。
   - 既存パーサーは個別の「建ぺい率」キーのみを参照していたため、値が `-` または未取得となり、建ぺい率・容積率が `None`（必須項目欠損）となっていた。
2. **athome mansion (所在階欠損)**:
   - 中古タウンハウス・テラスハウス等の低層連棟住宅物件において、`階建 / 階: 2階建` のように総階数のみ記載され、所在階が存在しないケースがある。
   - `_ensure_mansion_located_floor` が所在階欠損として `SkipPropertyException` を発生させるが、物件種目が「タウンハウス」「テラスハウス」の場合は戸建類似物件として正規にスキップ・ハンドリングされるべきである。

## 3. 改修内容
1. `src/crawler/package/parser/athomeParser.py`:
   - `AthomeTochiParser`:
     - 「建蔽率/容積率」「建ぺい率/容積率」「建蔽率／容積率」「建ぺい率／容積率」「建ぺい率・容積率」「建蔽率・容積率」等の複合キーからのフォールバック抽出ロジックを追加。
     - パーセント値が2つ以上存在する場合、1つ目を建ぺい率、2つ目を容積率として自動設定。
   - `AthomeMansionParser`:
     - `_ensure_mansion_located_floor`:
       - `specs.get("物件種目")` に「タウンハウス」「テラスハウス」が含まれる場合は、戸建類似物件（所在階なし正常）として `SkipPropertyException("Athome mansion townhouse/terrace house skipped: ...")` を明示的理由で送出。
