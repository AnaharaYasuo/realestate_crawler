# 仕様書: Issue #1551 割安物件通知一次スクリーニングにおける過疎駅・徒歩遠隔物件の足切りフィルタ仕様書

## 1. 概要 (Overview)
- **背景**:
  割安物件通知（`send_recommendations.py`）において、売出価格に対する理論価格の乖離（ディスカウント率）が高くても、最寄り駅が過疎駅（1日の乗降客数が極小）であったり、最寄り駅から徒歩15分以上の物件は、実需・投資双方の観点から流動性・資産性が著しく低く、通知対象として不適格である。
- **目的**:
  割安物件通知の一次スクリーニング判定（`_evaluate_candidate`）において、以下の2つの足切り条件（一次フィルタ）を導入し、適格な物件のみを二次スクリーニング（AI定性評価・レポート生成）およびSlack通知へ進める。
  1. 最寄り駅の1日あたり乗降客数が 10,000人 未満の物件を除外する。
  2. 最寄り駅から徒歩15分以上（`walk_min >= 15`）の物件を除外する。

## 2. 外部仕様・要件定義 (Requirements)

### 2.1 徒歩15分以上の足切りフィルタ
- 定数: `MAX_RECOMMEND_WALK_MINUTES = 14`（15分以上を除外、すなわち14分以内を許容）
- 判定仕様:
  - 物件の有効な最寄り駅アクセス経路（`station1..5`, `railwayWalkMinute1..5`, `railwayWalkMinute1..5Str`, `traffic` 等）から、徒歩所要分数（数値）を取得する。
  - 複数経路が存在する場合は、**最も近い駅への徒歩分数（最小徒歩分数）** を基準とする（例: 駅A徒歩16分、駅B徒歩8分の場合は8分とし除外しない）。
  - 最短徒歩分数が 15分以上（`min_walk_min >= 15`）の場合、一次スクリーニングで除外（スキップログを出力）。
  - 有効な駅情報や徒歩情報が一切記載されていない物件については、従前の仕様に倣い除外しない（フェールセーフ）。

### 2.2 乗降客数1万人未満の過疎駅足切りフィルタ
- 定数: `MIN_RECOMMEND_PASSENGER_VOLUME = 10000`（1日1万人未満を除外、10,000人以上を許容）
- 判定仕様:
  - 最寄り駅（徒歩分数が最短の駅、同着または単一の場合は `station1` 等）について、`query_station_volume(station_name)` により国土数値情報（`StationPotential` マスタ）の1日平均乗降客数を取得する。
  - 乗降客数が判明しており、かつ 10,000人未満（`0 <= volume < 10000`）である場合、一次スクリーニングで除外（スキップログを出力）。
  - 複数駅が記載されている場合:
    - 徒歩分数が14分以内の有効な駅のうち、いずれかの駅が乗降客数1万人以上を満たす（または乗降客数データ未登録・判定不能）であれば除外しない。
    - 徒歩14分以内の有効駅がすべて乗降客数1万人未満と判明している場合は除外する。
  - 駅マスタに乗降客数データが存在しない駅（`None`）や新設駅・路面電車電停等の場合は、データを理由に不当除外せず通過させる（誤検知防止・フェールセーフ）。

### 2.3 対象スコープ
- `src/crawler/scripts/ops/send_recommendations.py`:
  - `_evaluate_candidate(eval_rec, prop)`:
    - 既存のバス利用物件除外（`is_bus_access_property`）と同様、全種別共通の一次フィルタとして上記判定関数を実行。

## 3. テスト計画 (Testing Plan)
- `tests/unit/test_issue_1551_station_filter_recommendations.py`:
  - 最寄り駅乗降客数が 10,000人未満（例: 3,000人/日）の物件が除外されること。
  - 最寄り駅乗降客数が 10,000人以上（例: 25,000人/日、150,000人/日）の物件が通過すること。
  - 乗降客数データが未登録（`None`）の駅は除外されないこと。
  - 徒歩15分以上（例: 15分、20分）の物件が除外されること。
  - 徒歩14分以内（例: 5分、14分）の物件が通過すること。
  - 複数駅がある場合、1駅が徒歩20分でも別駅が徒歩8分かつ1万人以上なら通過すること。
  - 既存テストスイート（`test_send_recommendations.py`, `test_issue_1244_exclude_bus_recommend.py`, `test_two_stage_recommendations.py`, `test_architecture_harness.py`）が全てパスすること。
