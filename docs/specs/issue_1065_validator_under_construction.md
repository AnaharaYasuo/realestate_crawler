# 外部仕様書: 建築中・未完成物件における築年月バリデーションの緩和

## 1. 概要
不動産クローラーにおいて、新築戸建や未完成物件（現況が「建築中」「未完成」など）はスペック表に「築年月」が存在せず、代わりに「完成予定時期」「引渡時期」のみが記載されているケースが多数存在する。
これらを一律に `必須項目欠損 (築年月が未抽出)` としてエラー扱いすると、正常な物件データがクローリング失敗（needs_recrawl=True / needs_parser_fix=True）と誤判定され、監視アラートのノイズおよび自己修復タスクの滞留を引き起こす。

本改修では、`PropertyDataValidator` において建築中・未完成の物件については築年月の未設定を許容する仕様とする。

## 2. 仕様要件
- 対象種別: `kodate`, `mansion`, `invest_kodate` など居住用および投資用建物
- 判定条件:
  - 物件の `genkyo` または `currentStatus` に「建築中」「未完成」「新築（未完成）」が含まれる場合、あるいは備考/物件名等から未完成であることが明確な場合
- 動作:
  - 築年月（`chikunengetsu` / `chikunengetsuStr`）が空であっても、`ERR_MISSING_AGE`（必須項目欠損 (築年月が未抽出)）のエラー理由を付与しない。
  - すでに完成済みの物件については従来どおり築年月の必須検査を継続する。
