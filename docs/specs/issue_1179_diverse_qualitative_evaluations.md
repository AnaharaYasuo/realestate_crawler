## 1. 背景・課題分析
### 現状の事象
Slack推薦通知文に添付される「プロフェッショナル物件評価レポート」において、全物件（区分マンション、土地、一棟アパート、戸建）で以下の同一固定文章が出力されていた：
1. **最有効使用・容積余力**:
   「指定容積率に対する未消化余力（0%）を活かした将来の増床または高密度化建て替え適性あり。更地化による出口戦略も視野に入る。」（区分マンションや更地でも建て替え・更地化と出力）
2. **団長の辛口実戦目利き**:
   「表面利回りと積算の数字だけで涎垂らすなよ。いいか、積算出てるからと喜ぶ信託銀行の養分たちへ。前面道路3.2mの私道持ち分なし・セットバック要で、どこのまともな地銀がプロパーを引くんだよ...」（全物件で前面道路3.2m私道持ち分なし固定）
3. **物理・法的DDチェック**:
   「プロパン残債縛り」「退去発生時の賃料下落を織り込んだCFストレステスト」（区分や更地でも同一）

### 根本原因
- `report_generator.py` の `_generate_fallback_report` が物件種別（区分マンション、土地、一棟、戸建）や物件スペック（築年、未消化容積、接道等）を考慮せず、単一の静的文字列をフォーマットしていた。
- Gemini API（`gemini-3.8-flash` / `gemini-2.5-flash`）が呼び出せなかった場合（APIキー未設定、あるいはGCPクレジットクォータ402発生時）に、この単一フォールバックが常時発動していた。

## 2. 解決策・設計

### 2.1 物件種別（4大カテゴリ）に応じた動的定性評価の多層化
ルールベースフォールバック時（およびGeminiプロンプトのコンテキスト）において、以下の4大種別ごとに評価軸・目利き・DDチェックを完全分離する。

1. **中古マンション（区分）**:
   - **最有効使用**: 専有面積に応じた実需居住・リノベーション再販、またはファミリー/単身賃貸需要への適合性（建て替えや更地化は論外なので除外）。
   - **団長目利き**: 管理費・修繕積立金の総額バランス、大規模修繕履歴、専有部配管（PS・サヤ管）の更新状況、新耐震適合。
   - **DDチェック**: 管理規約（ペット・民泊・事務所利用・楽器可否）、修繕積立金総額・滞納額、専有部給排水管の専有・共用区分。

2. **土地（更地・古家付き）**:
   - **最有効使用**: 指定容積率と前面道路幅員に応じた「注文住宅用地」「建売2棟現場」「狭小アパートビルダー向け高密度利用」。
   - **団長目利き**: 前面道路幅員と接道長さ、高低差（擁壁・擁壁再構築費用）、水道引込管径（13mm vs 20mm）、セットバック要否。
   - **DDチェック**: 境界標の完全明示、越境物（雨樋・植栽）、地盤調査結果・液状化指定、私道持分と掘削承諾。

3. **一棟アパート・一棟マンション**:
   - **最有効使用**: 未消化容積率に応じた増床・建て替え余力、現況インカム回収後の更地化出口、またはサブリース解除・家賃引き直しCF。
   - **団長目利き**: レントロールの原契約日（サクラ・フリーレントAD盛り看破）、積算担保力と公道接道、プロパー融資妥当性。
   - **DDチェック**: レントロール原本突合、プロパンガス無償貸与契約の残債縛り、外壁・屋上防水の改修履歴、共用部電気水道メーター分離。

4. **中古戸建（投資・実需）**:
   - **最有効使用**: 実需自己居住、または低ロット再生賃貸（ジモティー・生活保護客付け向け高利回り運用）。
   - **団長目利き**: 雨漏り・白蟻・基礎クラックの有無、汲み取り/浄化槽から本下水接続費用、駐車スペース確保。
   - **DDチェック**: 床下・屋根裏の目視点検、私道持分・再建築可否（接道2m以上）、境界標。

### 2.2 シードナレッジ（団長RAG）の拡充
`SEED_KNOWLEDGE_BASE` に、区分マンション向け・土地向け・実需戸建向けのエピソードを拡充：
- `kb_mansion_kanri_syuzen`: マンションは管理を買え（修繕積立金不足と専有部給排水管の闇）
- `kb_tochi_road_suidou`: 土地の罠（水道管13mm引込とセットバック・擁壁の死に金）
- `kb_kodate_diy_renov`: 戸建てDIY再生と再建築不可の泥水CF

### 2.3 Gemini API / Secret Manager 連携の強化
- Google Cloud Secret Manager（`realestate-gemini-api-key-prod`）および `.env`（`GEMINI_API_KEY`）からAPIキーを自動読み込み。
- HTTP 402/429 等のクォータ制限時でも、多層化された高品質ルールベースフォールバックにより物件ごとに完全に異なるプロ視点・団長目利きが途切れず出力される設計とする。
