# Issue #1140 仕様書: 全不動産サイトにおける掲載終了判定の厳格化と包括テスト網羅

## 1. 概要 (Overview)
データベースに蓄積された実掲載終了URL（`PropertyEvaluation.delisted_at IS NOT NULL` 等）を活用し、全不動産サイト（28サイト超）を対象とした実機検証を実施。
各サイトが掲載終了・物件未存在となった際に返却するHTTPステータス（404/410）および画面上の明示的な文言（例:「掲載を終了しました」「該当する物件は存在しません」「お探しの物件は見つかりませんでした」等）の検知パターンを網羅・統一し、誤ってアクティブ物件として空文字登録されたりパーサーが異常終了したりすることを防止する。

## 2. 変更仕様 (Specifications)

### 2.1 掲載終了検知キーワードの拡充 (`ParserBase`)
- `ParserBase.LISTING_ENDED_TITLE_KEYWORDS` に以下のタイトル検知文言を追加：
  - `物件が見つかりませんでした`
  - `該当する物件は存在しません`
  - `該当する物件がありません`
  - `こちらの物件の掲載は終了致しました`
- `ParserBase.LISTING_ENDED_BODY_KEYWORDS` に以下の本文検知文言を追加：
  - `掲載終了いたしました`
  - `掲載終了しました`
  - `こちらの物件の掲載は終了致しました`
  - `ご指定の物件は、掲載終了いたしました`
  - `ご指定の物件は掲載終了いたしました`
  - `ご指定のページは見つかりませんでした`
  - `該当する物件は存在しません`
  - `該当する物件がありません`
  - `物件が見つかりませんでした`
  - `すでに成約済みとなったか掲載が終了`
  - `成約済みとなったか掲載が終了`

### 2.2 全サイト網羅の単体・統合テストの追加
- `src/crawler/tests/unit/test_all_sites_listing_ended_detection.py`:
  - 28サイトすべての掲載終了画面HTMLパターンに対して `ListingEndedException` が確実に送出されることを検証。
  - HTTP 404/410 で即座に `ListingEndedException` が送出されることを検証。
  - 通常のアクティブ物件ページでは例外が発生しないことを検証。
- 既存テスト `test_listing_ended_prevention.py` / `test_issue_1059_crawler_pipeline_fixes.py` の明示的文言要件との整合性を確保。
