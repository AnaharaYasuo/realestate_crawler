# 仕様書: Issue #1379 全サイト（97テーブル）のバス利用交通情報の網羅的パース対応および取得率100%化

## 1. 背景と課題
前回の改修（Issue #1372）では、住友不動産ステップ（sumifu_tochi）およびアットホーム（athome_tochi）の墨付き括弧付きバス表記に対応した。
しかし、データベース内の全97テーブル（全物件サイト・種別）を調査したところ、各サイト特有の表記揺れや構文差異により、多数のテーブルでバス情報が未取得（または誤って駅徒歩と混同）となっていることが判明した。

### 調査結果サマリー
1. **健美家（kenbiya_kodate, kenbiya_mansion等）**:
   - `traffic` に「最寄の沿線駅名及び駅までの徒歩分数または距離を表示。 バス利用の場合は最寄駅からのバス乗車時間及び、停留所からの徒歩分数を表示。」という定型注記文言がベタ書きされており、実際の物件データではない。
   - 対策: 注記文言のみの場合はバス利用・交通情報としてパースせずスキップする。
2. **東急リバブル（tokyu_kodate, tokyu_tochi等）**:
   - `千代田・常磐緩行線「北千住」駅バス14分 「島根町」停 徒歩4分東武伊勢崎・大師線「西新井」駅徒歩22分`
   - 区切りスペースや改行なしで路線が連続連結されており、かつ `「...」停 徒歩X分` の表記。
3. **大京穴吹不動産（daikyo_mansion等）**:
   - `バス停 「西一之江四丁目」 徒歩4分 総武本線 「新小岩」駅 までバス18分`
   - バス停が先頭に来て、後ろに `[路線名] [駅名]駅 までバスX分` が続く逆順構文。
   - `札幌市東西線 「バスセンター前」駅 徒歩5分` など、「バスセンター前」という駅名に対する誤判定防止が必要。
4. **トータテ（totate_tochi, totate_kodate等）**:
   - `小田急電鉄小田原線「相模大野」駅 まで 物件から徒歩3分の「御園五丁目」バス停乗車 バス14分`
   - `駅 まで 物件から徒歩X分の「...」バス停乗車 バスY分` という特有文章構文。
5. **LIFULL HOME'S（homes_kodate, homes_tochi等）**:
   - `小田急小田原線 町田駅 バス10分 徒歩1分（バス：木曽都営入口停留所）`
   - `バス：...停留所`、`徒歩X分（バス：...）` 構文。
6. **小田急不動産（odakyu_kodate等）**:
   - `小田急江ノ島線「長後」駅バス14分 大邸 停歩5分`
   - `停歩X分` かつバス停名が直前にベタ書き。
7. **すまい1（sumai1_kodate等）**:
   - `小田急電鉄小田原線 「町田」駅 バス18分 「金井小学校入口」バス停下車 徒歩8分`
   - `「...」バス停下車 徒歩X分` 構文。
8. **みずほ不動産販売（mizuho_kodate等）**:
   - `折手バス停`、`バス停『相鉄バス 浜田歴史公園'`
   - 路線・駅名が存在せずバス停名のみ記載されているパターン。駅名は空とし、バス停名のみ格納。

## 2. 改修方針 (Architecture & Implementation)

### 2.1 基底パーサー (`BaseParser._apply_bus_fields` & `_extract_bus_stop_from_text`) の拡充
基底パーサーであらゆるバリエーションを共通吸収する：
- **バス利用判定**:
  - `バスセンター`、`注記文言`（「最寄の沿線駅名及び...」）を除外。
  - `【?バス(?:乗車)?】?\s*(\d+)分`
  - `バス(?:乗車)?\s*(\d+)分`
- **バス停名抽出**:
  - `「([^」]+)」(?:停|バス停)(?:下車|乗車)?`
  - `『([^』]+)』(?:停|バス停)?`
  - `(?:バス|バス停|停)\s*[:：]?\s*([^\s（()）]+)(?:停留所|停)?`
  - `([^\s（()）]+)\s*(?:停歩|バス停下車|停留所)`
- **停歩・徒歩分数抽出**:
  - `(?:停歩|徒歩)\s*(\d+)分`
  - `物件から徒歩\s*(\d+)分`

### 2.2 個別サイト特有パターンのプリプロセッサ導入
- `tokyuParser`: 複数路線の連結部分（`分(?=[^\s\d]+(?:線|駅))`）で適切にトークン分割。
- `daikyoParser`: `バス停 ... 徒歩X分 ... 駅 までバスY分` を標準の `路線 駅 バスY分(停 ...) 徒歩X分` に正規化。
- `totateParser`: `駅 まで 物件から徒歩X分の「...」バス停乗車 バスY分` を正規化。
- `mizuhoParser`: 駅名なしバス停単独表記のハンドリング。

### 2.3 クレンジングバッチ (`cleanse_bus_traffic_data.py`) の全テーブル対応
- 全97テーブル（またはバスデータを含む全テーブル）を対象に指定可能にし、一括で再パース・更新できるコマンドオプションを追加。
