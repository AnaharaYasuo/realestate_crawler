# 仕様書: Issue #1244 割安物件ピックアップ対象からバス利用物件を除外

## 1. 目的
お宝物件（割安物件・投資物件）の Slack ピックアップ対象から、最寄り駅への到達にバス利用が必要な物件を除外する。

## 2. 判定仕様
- 対象: `src/crawler/scripts/ops/send_recommendations.py` の `_evaluate_candidate`（全物件種別共通の入口）。
- アクセス経路 `N = 1..5` のうち、`stationN` が記載された経路を「有効経路」とする。
- 経路が「バス利用」とは、`busUseN` が真値、または `busWalkMinuteN > 0` の場合。
- 有効経路が 1 つ以上あり、**全ての有効経路がバス利用**の場合に「バス利用物件」と判定し、ピックアップ対象から除外する。
- 徒歩のみで到達可能な経路が 1 つでもあれば対象に残す。駅情報が無い物件（判定不能）は除外しない。

## 3. テスト
- `tests/unit/test_issue_1244_exclude_bus_recommend.py`: バス単独経路の除外、徒歩経路併記時の残存、駅情報なし時の残存、投資物件への適用を検証。
