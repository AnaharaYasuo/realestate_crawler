## 3. テスト実行手順

- **全テスト実行（単体＋ライブ統合テスト）**:
  ```bash
  pytest src/crawler/tests/
  ```
- **ライブ統合テストのみ実行**:
  ```bash
  pytest src/crawler/tests/integration/test_live_reachability.py -v
  ```
- **オフライン単体テストのみ実行（ライブ統合テスト除外）**:
  ```bash
  pytest src/crawler/tests/ -m "not live"
  ```
